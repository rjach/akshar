# Security Policy

Akshar is a static, frontend-only site: there are no accounts, no server and no stored user data outside your own browser.

## Reporting a vulnerability

Report privately through [GitHub security advisories](https://github.com/rjach/akshar/security/advisories/new) or by email to [hello@rojanacharya.com](mailto:hello@rojanacharya.com). Please do not open a public issue.

Include:

- a description of the vulnerability
- steps to reproduce or a proof of concept
- the impact
- screenshots, if useful

You will get an acknowledgement within a few days and updates until it is fixed.

## Scope

In scope: the code in this repository and the site at https://akshar.rojanacharya.com.

Vulnerabilities in upstream Monkeytype code that also affect monkeytype.com should also be reported to the [Monkeytype maintainers](https://github.com/monkeytypegame/monkeytype/security).
